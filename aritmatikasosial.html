BAB 1: Harga Jual, Harga Beli, Untung, dan Rugi

🟢 Kasus Untung (Harga Jual > Harga Beli)

Seorang pedagang membeli sepeda seharga \(\text{Rp } 1.000.000\) dan berhasil menjualnya kembali dengan harga \(\text{Rp } 1.200.000\). Pedagang tersebut mendapatkan untung sebesar \(\text{Rp } 200.000\).

🔴 Kasus Rugi (Harga Jual < Harga Beli)

Pedagang lain membeli gawai seharga \(\text{Rp } 2.000.000\). Karena terdapat goresan fisik, gawai tersebut terpaksa dijual hanya seharga \(\text{Rp } 1.700.000\). Pedagang tersebut mengalami kerugian sebesar \(\text{Rp } 300.000\).

Rumus Persentase Finansial

Persentase Untung (\(\%U\)):

$$\%U = \frac{\text{Untung}}{\text{Harga Beli}} \times 100\%$$

Persentase Rugi (\(\%R\)):

$$\%R = \frac{\text{Rugi}}{\text{Harga Beli}} \times 100\%$$

Dasar utama: Nilai untung atau rugi selalu dibandingkan terhadap Harga Beli awal (modal).
Slide 6: Kasus Rekayasa Nilai

Menentukan Harga Beli & Jual Berbasis Persentase

📋 Skenario Analisis:

Pak Rudi menjual sebuah mesin cuci seharga \(\text{Rp } 2.300.000\) dan dari penjualan tersebut ia sudah mendapatkan keuntungan bersih sebesar \(15\%\). Berapakah modal awal (Harga Pembelian) yang dikeluarkan Pak Rudi untuk membeli mesin cuci tersebut?

💡 Rumus Konfigurasi Balik:

Jika Untung: HB = \(\frac{100}{100 + \%U} \times \text{HJ}\)
Jika Rugi: HB = \(\frac{100}{100 - \%R} \times \text{HJ}\)

Penyelesaian Kasus Pak Rudi: \(\text{HB} = \frac{100}{115} \times 2.300.000 = \text{Rp } 2.000.000\).

Ingat bahwa Harga Jual (\(\text{HJ}\)) saat untung setara dengan \(100\% + \%U\).

Slide 10: Pendalaman Komparasi

Kalkulasi Strategis Diskon Bertingkat

⚠️ Miskonsepsi Fatal Diskon Bertingkat:

Diskon tertulis \(50\% + 50\%\) **BUKAN BERARTI GRATIS (Diskon \(100\%\))**. Sistem ritel memberlakukan potongan pertama pada harga awal, lalu potongan kedua diaplikasikan pada nilai sisa harga setelah potongan pertama tersebut dihitung.

🧮 Contoh Simulasi Nyata:

Sepasang sepatu dihargai \(\text{Rp } 400.000\) diberi promo diskon bertingkat \(50\% + 20\%\).

  1. Potongan Tahap 1: \(50\% \times 400.000 = \text{Rp } 200.000\). Sisa Harga = \(\text{Rp } 200.000\).
  2. Potongan Tahap 2: \(20\% \times 200.000 = \text{Rp } 40.000\).
  3. Harga Akhir Kasir = \(200.000 - 40.000 = \mathbf{\text{Rp } 160.000}\).
Formula praktis harga akhir untuk diskon bertingkat \(a\% + b\%\) adalah \((100-b)\% \times (100-a)\% \times \text{Harga Awal}\).
Slide 11: Analisis Massa Modul

Korelasi dan Perbandingan Bruto, Tara, Neto

Hubungan Matematis Mutlak

$$\text{Bruto} = \text{Neto} + \text{Tara}$$

$$\text{Neto} = \text{Bruto} - \text{Tara}$$

$$\text{Tara} = \text{Bruto} - \text{Neto}$$

Persentase Tara (\(\%T\)) terhadap Bruto

Nilai persentase potongan berat penyusutan pembungkus (tara) selalu dipatok dan dihitung terhadap total berat kotor benda keseluruhan (bruto).

$$\text{Berat Tara} = \%T \times \text{Bruto}$$

Contoh: Karung beras bertuliskan Bruto \(50 \text{ kg}\), Tara \(1\%\). Maka berat tara penampung wadah = \(1\% \times 50 = 0,5 \text{ kg}\). Sehingga berat bersih beras (neto) = \(49,5 \text{ kg}\).

Dalam perdagangan partai besar, harga beli komoditas hanya dikenakan pada berat neto murni barang.

Slide 14: Dunia Perbankan

Konsep Akumulasi Tabungan Mandiri

📌 Batasan Rumus Bunga Tunggal (Bulanan):

Bunga tunggal dihitung eksklusif hanya berdasarkan modal utama tabungan awal saja yang konstan tiap periode.

$$B = \frac{n}{12} \times b\% \times M_0$$

Keterangan: \(B\) = Nominal bunga didapat, \(n\) = Jumlah bulan berjalan, \(b\%\) = Suku bunga per tahun, \(M_0\) = Modal simpanan dasar.

📝 Contoh Kasus & Penyelesaian:

Susi menabung modal \(\text{Rp } 4.000.000\) di bank dengan bunga tunggal \(6\%\) per tahun. Berapakah jumlah total nominal uang Susi setelah mengendap selama 8 bulan?

• Bunga: \(\frac{8}{12} \times \frac{6}{100} \times 4.000.000 = \text{Rp } 160.000\)

• Total Uang Akhir: \(4.000.000 + 160.000 = \mathbf{\text{Rp } 4.160.000}\)

Suku bunga perbankan nasional umumnya dipatok dalam satuan persen per tahun (p.a / per annum).
Slide 15: Kebijakan Fiskal

Kalkulasi Pajak Negara: PPN dan PPh

🛍️ 1. PPN (Pajak Pertambahan Nilai)

Pajak yang dikenakan pada transaksi jual beli barang/jasa mewah. Sifatnya **menambah** total biaya pembayaran konsumen belanja.

Contoh Kasus:

Membeli laptop seharga \(\text{Rp } 8.000.000\) dengan beban PPN sebesar \(11\%\).

• PPN = \(11\% \times 8.000.000 = \text{Rp } 880.000\)
• Total bayar = \(8.000.000 + 880.000 = \mathbf{\text{Rp } 8.880.000}\)

💼 2. PPh (Pajak Penghasilan)

Pajak yang dibebankan atas penghasilan atau gaji yang diterima pegawai. Sifatnya **mengurangi** total uang bawa pulang bersih.

Contoh Kasus:

Pegawai menerima gaji pokok \(\text{Rp } 5.000.000\) kena potongan tarif PPh sebesar \(5\%\).

• PPh = \(5\% \times 5.000.000 = \text{Rp } 250.000\)
• Gaji Bersih diterima = \(5.000.000 - 250.000 = \mathbf{\text{Rp } 4.750.000}\)
Pajak dikelola langsung oleh negara demi pemerataan pembangunan fasilitas publik.
Slide 16: Finansial Tingkat Lanjut

Bunga Tunggal Bersanding Bunga Majemuk

⚖️ Perbedaan Esensial Komparatif:

Bunga Tunggal menghasilkan nominal laba konstan flat berulang tiap jangka waktu karena acuan pokoknya tidak berubah. Sedangkan **Bunga Majemuk (Bunga Berbunga)** menyertakan nominal profit periode lalu ke modal baru, menciptakan pertumbuhan eksponensial yang jauh lebih akseleratif.

🎛️ Rumus Tabungan Akhir Majemuk:

$$M_t = M_0 \times (1 + i)^t$$

Keterangan: \(M_t\) = Uang akhir periode ke-\(t\), \(i\) = Suku persen bunga majemuk, \(t\) = Jangka waktu.

📊 Studi Kasus Perbandingan Nyata:

Modal investasi awal \(\text{Rp } 10.000.000\) dilepas dengan suku bunga kompetitif \(10\%\) per tahun selama jangka target waktu 2 tahun.

🎯 **Skema Tunggal:** Tahun 1 untung \(1 \text{ jt}\), Tahun 2 untung \(1 \text{ jt}\). Total uang akhir setelah 2 tahun = \(\mathbf{\text{Rp } 12.000.000}\).

🚀 **Skema Majemuk:** Akhir Tahun 1 uang tumbuh jadi \(11 \text{ jt}\). Bunga Tahun 2 dihitung dari baselining baru: \(10\% \times 11 \text{ jt} = 1,1 \text{ jt}\). Total uang akhir setelah 2 tahun = \(\mathbf{\text{Rp } 12.100.000}\).

Bunga majemuk merupakan basis penggerak utama instrumen investasi modern reksadana dan saham.

📊 BAB 1: Finansial Dagang

• \(\text{Untung} = \text{HJ} - \text{HB}\)

• \(\text{Rugi} = \text{HB} - \text{HJ}\)

• \(\%U = \frac{\text{Untung}}{\text{HB}} \times 100\%\)

• \(\text{HB (Untung)} = \frac{100}{100+\%U} \times \text{HJ}\)

🏷️ BAB 2: Berat & Diskon

• \(\text{Diskon Nominal} = \%D \times \text{Harga KOTOR}\)

• \(\text{Bruto} = \text{Neto} + \text{Tara}\)

• \(\text{Neto} = \text{Bruto} - \text{Tara}\)

• \(\text{Tara Nominal} = \%T \times \text{Bruto}\)

🏦 BAB 3: Bank & Pajak

• \(\text{Bunga Tunggal} = \frac{n}{12} \times b\% \times M_0\)

• \(\text{PPN Akhir} = (100\% + \%PPN) \times \text{Harga}\)

• \(\text{PPh Bersih} = (100\% - \%PPh) \times \text{Gaji}\)

• \(\text{Majemuk} = M_t = M_0(1+i)^t\)
